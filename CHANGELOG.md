# Changelog

## 1.1.0

- a GCP category of Google Cloud service icons, loaded from Iconify's gcp set
- an Azure category of Azure service icons, built into the extension so they load instantly
- a Kubernetes category with all 38 official Kubernetes icons, from pods and deployments to the API server and kubelet, loaded from Iconify's k8s set
- labels spelled the way each cloud names its services, such as BigQuery, Pub/Sub, Azure Functions and Azure Cosmos DB

## 1.0.4

- the panel now uses Drawdy's own colours and font and matches the other icon pickers: chips that scroll with a fade, size and style controls that show the selected option in grey instead of lime, and a search box with a glyph
- a shorter search hint that is no longer cut off

## 1.0.3

- a short GIF on the listing page that shows searching for logos and dragging them onto the board in action

## 1.0.2

- a label sits centred under its icon, and an icon with a label is placed as one group, so the two move together

## 1.0.1

- a clearer listing page: what the extension is for, how to use it, tips and privacy, in plain words

## 1.0.0

First public release

- One palette for architecture diagrams: Lucide building blocks and curated cloud, AWS, database, DevOps, language, framework, AI and messaging logos, in category chips
- Every AWS service logo from SVG Logos, labelled the way diagrams spell them, such as AWS Lambda and AWS S3
- Ranked search across the curated icons, with an Other logos section from the full SVG Logos set when few of them match
- Drag an icon to where you let go, or click to add it in view; repeated clicks line up in rows instead of stacking
- Labels on by default, sizes S to XL, and a colour and stroke width for Lucide icons
- Icons keep their proportions and stay sharp when you zoom in; a Recent row keeps your last 12
